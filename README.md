# 14 Days of Interactions

One UI micro-interaction built and posted daily for 14 days.

**Live collection:** `https://Kanishksingh3012.github.io/interactions-2026`

## Stack
- Vanilla HTML / CSS / JS — no framework, no build step
- [GSAP](https://gsap.com/) via CDN for motion
- Prototyped in Claude Design, built in Claude Code

## Structure
```
interactions-2026/
├── index.html          # landing page, links to all days
├── days/
│   ├── day-01-magnetic-button.html
│   ├── day-02-....html
│   └── ...
└── README.md
```

Each file in `days/` is self-contained — open it directly in a browser, no server or install needed.

## Running locally
Clone the repo and open `index.html` in a browser. No dependencies to install.

```
git clone https://github.com/yourusername/interactions-2026.git
cd interactions-2026
open index.html
```
